# Meta Quest 3 VR

Open the GitHub Pages version in the Meta Quest Browser and select **In VR starten**.

## Controls

- Trigger: point at and activate spatial menu controls
- B or Y: open or close the cockpit menu
- Left thumbstick: yaw and pitch
- Right thumbstick up/down: increase or decrease throttle
- Hold the Meta button: recenter the seated view

## Spatial menu

The cockpit menu provides VR-native access to:

- flight status and control help
- cargo inventory
- available research and research start actions
- unlocked crafting recipes and crafting actions
- VR flight, pitch, bloom, and session settings

For the most comfortable experience, play seated and recenter the view after entering VR.
